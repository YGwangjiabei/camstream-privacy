流光之眼电脑接收器

Windows 版电脑端，用于接收手机摄像头画面，并输出到 OBS Virtual Camera。新版默认使用悬浮控制条，不显示命令行；需要看画面时点击“预览”。

下载安装

下载并运行安装器，然后按向导完成安装。

下载 CamStreamReceiverSetup-1.0.0.exe 下载上一版备用包

如果新版异常，可安装上一版备用包回退；备用包走固定归档链接，不占用当前下载页部署体积。

使用步骤

  1. 在 Windows 电脑安装本接收器。
  2. 安装 DevEco Studio 或 HO-Kit，让电脑具备 hdc.exe 手机连接工具。
  3. 用 USB 连接并解锁 HarmonyOS 手机，允许 HDC / USB 调试授权。
  4. 打开“流光之眼电脑接收器”，等待悬浮控制条显示连接状态。
  5. 在手机 App 中点击“开始推流”。
  6. 如果画面方向不对，用悬浮控制条按钮调整；需要看画面时点击“预览”，需要大画面时点击“全屏”。
  7. 在会议软件中选择 OBS Virtual Camera。

悬浮窗和调试模式

普通入口：默认打开悬浮控制条，不显示命令行窗口。控制条会显示连接状态、虚拟摄像头状态和输入/输出 FPS；更多面板会显示 HDC 路径、手机序列号、丢帧数、队列延迟和最近错误。

预览：点击“预览”即可打开或关闭普通画面预览，关闭预览不会影响虚拟摄像头输出。

全屏：点击“全屏”会先打开预览窗口并切换预览全屏，再次点击退出预览全屏；它不改变会议软件里的虚拟摄像头输出。

调试模式：安装后还会提供“流光之眼电脑接收器（调试模式）”，用于查看 HDC、USB 转发、H.264 和虚拟摄像头日志。

画面方向调整

普通模式默认禁用键盘快捷键，避免中文输入法或打字误触。请使用悬浮控制条按钮完成旋转、镜像、预览、全屏、重置和退出。

方向设置会同时作用于预览窗口和 OBS Virtual Camera 输出。90/270 度旋转会保持比例；如果竖屏虚拟摄像头不可用，会回退到横屏画布内等比显示，避免人物变胖。

没有虚拟摄像头怎么办

如果电脑没有可用的虚拟摄像头后端，接收器会打开预览窗口。你可以用 OBS 的“窗口采集”捕获这个预览窗口，再通过 OBS 虚拟摄像头输出给会议软件。

常见问题

找不到手机：重新插拔 USB，保持手机解锁，并确认 HDC 授权。

找不到 hdc.exe：安装 DevEco Studio / HO-Kit，或在悬浮控制窗里点击“选择 HDC”。

一直等待：请回到手机 App，确认已经点击“开始推流”。

会议软件黑屏：确认接收器窗口已经显示收到帧，并在会议软件中选择 OBS Virtual Camera。
