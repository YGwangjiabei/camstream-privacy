流光之眼电脑接收器

Windows 版电脑端，用于接收手机摄像头画面，并输出到 OBS Virtual Camera。默认推荐低延迟入口，需要调方向时可打开预览。

下载安装

下载并运行安装器，然后按向导完成安装。

下载 CamStreamReceiverSetup-1.0.0.exe

如果下载链接暂未发布，请联系开发者获取同名安装包。

使用步骤

  1. 在 Windows 电脑安装本接收器。
  2. 安装 DevEco Studio 或 HO-Kit，让电脑具备 hdc.exe 手机连接工具。
  3. 用 USB 连接并解锁 HarmonyOS 手机，允许 HDC / USB 调试授权。
  4. 打开“流光之眼电脑接收器（低延迟）”。需要看预览按钮时，打开“带预览”入口或在控制台按 p。
  5. 在手机 App 中点击“开始推流”。
  6. 如果画面方向不对，用快捷键 [、]、h、v、r 调整。
  7. 在会议软件中选择 OBS Virtual Camera。

低延迟和带预览

低延迟入口：默认不打开预览窗口，只输出虚拟摄像头，适合会议软件长期使用。

带预览入口：启动时打开控制预览窗口，适合第一次调方向或排查连接。预览可能增加延迟，调好后可以按 p 关闭。

画面方向调整

快捷键：[ 左转，] 右转，h 水平镜像，v 垂直镜像，f 全屏，r 重置，p 开关预览，q 退出。

方向设置会同时作用于预览窗口和 OBS Virtual Camera 输出。90/270 度旋转时，输出尺寸会从横向切换为竖向。

没有虚拟摄像头怎么办

如果电脑没有可用的虚拟摄像头后端，接收器会打开预览窗口。你可以用 OBS 的“窗口采集”捕获这个预览窗口，再通过 OBS 虚拟摄像头输出给会议软件。

常见问题

找不到手机：重新插拔 USB，保持手机解锁，并确认 HDC 授权。

找不到 hdc.exe：安装 DevEco Studio / HO-Kit，或在接收器提示时粘贴 hdc.exe 的完整路径。

一直等待：请回到手机 App，确认已经点击“开始推流”。

会议软件黑屏：确认接收器窗口已经显示收到帧，并在会议软件中选择 OBS Virtual Camera。
