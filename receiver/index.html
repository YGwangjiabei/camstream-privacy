流光之眼电脑接收器

Windows 电脑端，用于接收手机摄像头画面，并输出到 OBS Virtual Camera。新版默认使用悬浮控制条，不显示命令行窗口。

下载安装

下载并运行安装器，按向导完成安装。安装后会有普通入口和调试入口，普通用户打开“流光之眼电脑接收器”即可。

使用步骤

  1. 在 Windows 电脑安装本接收器。
  2. 安装 DevEco Studio 或 HO-Kit，让电脑具备 hdc.exe 手机连接工具。
  3. 用 USB 连接并解锁 HarmonyOS 手机，允许 HDC / USB 调试授权。
  4. 打开“流光之眼电脑接收器”，等待悬浮控制条显示连接状态。
  5. 在手机 App 中点击“开始推流”。
  6. 如果方向不对，用悬浮控制条调整旋转、镜像、预览和全屏。
  7. 在会议软件中选择 OBS Virtual Camera。

本版修复重点

  • 预览稳定：预览窗口和接收后端分离，打开/关闭预览不应中断虚拟摄像头输出。
  • 竖屏比例：旋转后保持等比缩放，竖屏画面放入横屏画布，不再把人物拉宽。
  • 更多面板：详细状态面板支持滚动，可查看 HDC、设备、FPS、丢帧、队列延迟和最近错误。

悬浮窗和调试模式

普通入口：默认打开悬浮控制条，不显示命令行窗口。控制条会显示连接状态、虚拟摄像头状态和输入/输出 FPS。

预览：点击“预览”打开或关闭普通画面预览。关闭预览不会影响 OBS Virtual Camera 输出。

全屏：点击“全屏”会先打开预览窗口，再切换预览全屏。再次点击退出预览全屏。

调试模式：安装后还会提供“流光之眼电脑接收器（调试模式）”，用于查看 HDC、USB 转发、H.264 和虚拟摄像头日志。

常见问题

找不到手机：重新插拔 USB，保持手机解锁，并确认 HDC 授权。

找不到 hdc.exe：安装 DevEco Studio / HO-Kit，或在悬浮控制条“更多”里选择 HDC。

一直等待：回到手机 App，确认已经点击“开始推流”。

会议软件黑屏：确认接收器已经收到帧，并在会议软件中选择 OBS Virtual Camera。
